# OLX → Telegram watcher

Следит за поиском на OLX.ua и присылает в Telegram **новые** объявления.
Работает бесплатно на **GitHub Actions** (крон раз в 30 минут).

По умолчанию настроен на твой фильтр:
**легкові автомобілі · Запорізька область · не розмитнені · до 200 000 грн**
(`category_id=108`, `region_id=17`, `filter_enum_cleared_customs[0]=no`,
`filter_float_price:to=200000`). Фильтр цены работает в гривнах — OLX сам
конвертирует объявления в USD в грн-эквивалент.

## Как это работает

- Каждые 30 минут Actions запускает `olx_watch.py`.
- Скрипт дёргает внутренний JSON API OLX, **подменяя TLS-фингерпринт под Chrome**
  (`curl_cffi`) — иначе OLX отдаёт 403.
- Виденные объявления хранятся в `seen.json` (коммитится обратно в репо).
- Первый запуск — «тихий»: просто запоминает текущие объявления, без спама.
  Со второго запуска шлёт только то, чего раньше не было.

## Установка (10 минут)

### 1. Создать Telegram-бота
1. В Telegram напиши **@BotFather** → `/newbot` → задай имя.
2. Скопируй **токен** вида `123456:ABC-DEF...`.

### 2. Узнать свой chat_id
1. Напиши своему новому боту любое сообщение (например `привет`).
2. Открой в браузере (подставь токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найди `"chat":{"id":123456789,...}` — это твой **chat_id**.

> Хочешь слать в группу/канал — добавь бота туда и возьми id оттуда
> (у групп id с минусом, напр. `-1001234567890`).

### 3. Залить в GitHub
1. Создай новый репозиторий (можно **private** — Actions бесплатны и для приватных).
2. Залей содержимое этой папки в корень репо:
   ```
   olx_watch.py
   requirements.txt
   .github/workflows/olx.yml
   README.md
   ```

### 4. Добавить секреты
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
- `TELEGRAM_BOT_TOKEN` = токен из шага 1
- `TELEGRAM_CHAT_ID` = chat_id из шага 2

### 5. Разрешить Actions писать в репо
Settings → **Actions → General → Workflow permissions** →
выбрать **Read and write permissions** → Save.
(Нужно, чтобы джоба коммитила `seen.json`.)

### 6. Запустить
Вкладка **Actions** → workflow **OLX watcher** → **Run workflow**.
- Первый запуск — тихий (запомнит текущие).
- Дальше крон сам будет раз в 30 минут присылать новые авто.

## Поменять фильтр

Открыл нужный поиск на OLX → смотри URL. Разверни блок `env:` в
`.github/workflows/olx.yml` и задай:
- `OLX_CATEGORY_ID` — id категории,
- `OLX_REGION_ID` — id области,
- `OLX_EXTRA_PARAMS` — доп. фильтры через `&`, напр.
  `filter_enum_cleared_customs[0]=no&filter_float_price:to=5000`.

region_id для нужной области можно подсмотреть на странице OLX
(в исходнике страницы есть `"regionId":17`).

## Заметки

- Крон GitHub Actions может запаздывать на 5–15 мин при нагрузке — для «раз в 30 мин» это ок.
- Коммиты `seen.json` держат workflow «живым» (приватный repo иначе отключает крон
  после 60 дней без активности).
- Лимит бесплатных Actions-минут для приватных репо — 2000/мес; этот джоб ест ~1 мин/запуск
  ≈ 1440 мин/мес. Если впритык — поставь крон `*/60` (раз в час) или сделай репо публичным
  (тогда минуты безлимитны).

## Локальный запуск / отладка

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
python olx_watch.py
```
